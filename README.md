# IUVPY
# Pronóstico del IUV sobre Paraguay

Automatización de pronósticos del Índice Ultravioleta con GFS y CAMS/ECMWF, publicación de mapas y archivo de corridas en Google Drive.

## Instalación
Ver [README_SETUP.md](README_SETUP.md) para cargar archivos, configurar secretos y habilitar GitHub Pages.

## Modelos y horarios UTC
- CAMS 00Z: disponible desde las 10:00 UTC
- GFS 12Z: disponible desde las 18:00 UTC
- CAMS 12Z: disponible desde las 22:00 UTC

## Página
GitHub Pages se publica desde GitHub Actions. Tras habilitar Pages con origen **GitHub Actions**, la página estará en:
https://meteik.github.io/iuvpy/
